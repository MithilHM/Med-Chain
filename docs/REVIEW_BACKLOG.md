### This pass
| Was | Finding | Resolution |
| --- | --- | --- |
| P0 (new) | Graph side-effect profiles returned **hardcoded invented results** ("Metformin → Nausea, 5 patients") when nothing matched; every edge defaulted to `patient_count: 4`; the live Cypher used relationship names the rebuild never wrote. | Profiles are computed from patient-level `EXPERIENCED` edges, return `[]` when nothing matches, and use the written relationship names. Test added. |
| P1 | Neo4j rebuild deleted the live graph before writing the new one; patient nodes carried MRNs. | Generation-tagged rebuild with an atomic swap; a failed rebuild leaves the previous projection live; nodes carry keyed pseudonyms only; connectivity and freshness health checks. |
| P1 | No hospital SSO, MFA, or deprovisioning. | OIDC (PKCE, JWKS, nonce, at_hash, `amr`), SCIM 2.0, TOTP with replay protection and recovery codes, MFA-required roles, a bootstrap-admin script. Production refuses to start without SSO or admin MFA. |
| P1 (new) | Real-time events from the MLLP listener process never reached dashboards, which live on the API processes. | PostgreSQL `LISTEN/NOTIFY` relay for every process, with local fallback. CI test included. |
| P1 (new) | Visit-based access never expired, so ending care-team access after discharge had no effect. | Discharged visits grant access only for `CARE_TEAM_POST_DISCHARGE_DAYS`; cancelled visits grant nothing; optional `VISIT_RELATIONSHIP_ACCESS_DAYS` cap. The audit and document lists use the same rule. |
| P1 | No duplicate-record handling, cancellations, or transfers. | `A02`, `A11`, `A13`, and approval-gated `A40` merges with a two-person rule. |
| P2 | Patient names were not stored, so clinicians could not confirm identity. | AES-GCM-encrypted names with a keyed blind index; shown to care roles only; captured from `PID-5` and FHIR. |
| P2 | Login rate limit was per process. | Database-backed limiter shared by all replicas. |
| P2 | No alerting or metrics. | Monitor with an alert lifecycle and webhook, and a Prometheus `/metrics` endpoint. |
| P2 | No key identifiers or rotation. | Key ring with key IDs in every ciphertext, a rotation job and script, and a status endpoint. |
| P2 | Per-row queries in the timeline, document list, and audit list. | Eager loading, batched lookups, and pagination. |
| P2 | Fixed gas and legacy pricing; key only from env. | Gas estimation, EIP-1559 fees, confirmations, and signing key from a secret file. |
| P2 (new) | The migration autogenerated a boolean default as `DEFAULT 0`, which is invalid on PostgreSQL. | Written as `sa.false()`, and caught before CI. |
| P2 (new) | The admin page's outbox list called a non-existent endpoint and always showed nothing. | Pointed at `/admin/outbox/events`. |
